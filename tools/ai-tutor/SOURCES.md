# Sources

Every Incubator wiki guide that feeds a lesson, and which lesson it feeds.

[ROADMAP.md](ROADMAP.md) has the same mapping the other way round, grouped by
lesson. This page is the reverse index: start from a guide and find where it is
taught.

Themes and descriptions come from
[`tools/seealso/resources.yml`](../seealso/resources.yml), the maintained index
of Incubator training material. Every guide below is used by exactly one lesson,
with none used twice. Not every indexed guide feeds a lesson: the index also
covers material the lessons do not draw on. Lesson 3 additionally uses the
[ASF Code of Conduct](https://www.apache.org/foundation/policies/conduct), which
lives on the main ASF site rather than the wiki.
