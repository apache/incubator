    Apache Grails IntelliJ Plugin Codebase Intellectual Property (IP) Clearance Status

    Description

    IntelliJ IDEA plugin for Apache Grails (GSP language, project model, run configurations, GORM/taglib support, etc.). Developed by JetBrains s.r.o. and previously available in the grails/ subtree of https://github.com/JetBrains/intellij-obsolete-plugins under the Apache License 2.0.

    Project info

    • Which PMC will be responsible for the code: Apache Grails PMC
    • Into which existing project/module: a new GitHub repo, apache/grails-intellij-plugin
    • Officer or member managing donation: James Fredley (VP, Apache Grails)
