    Solr MCP Codebase Intellectual Property (IP) Clearance Status

    Description

    Solr MCP lets you Search, index, and manage Apache Solr collections using natural language — no need to hand-craft Solr queries, build filter expressions, or memorize the admin API using the MCP protocol.

    Provenance chain:

    • Single-author work by Aditya Parikh, contributed under the author's ICLA (see LEGAL-716)

    Project info

    • Which PMC will be responsible for the code: Apache Solr PMC
    • Into which existing project/module: Solr MCP — a new sub-project under the Apache Solr umbrella
    • Officer or member managing donation: Eric Pugh (Apache Member, epugh@apache.org)
