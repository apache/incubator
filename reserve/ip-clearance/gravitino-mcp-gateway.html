    Apache Gravitino MCP Gateway Codebase Intellectual Property (IP) Clearance Status

    Description

    The Gravitino MCP Gateway was originally developed at Roku, Inc. as AgentBox. It is a service that sits between AI clients and MCP (Model Context Protocol) servers: people sign in once with their identity provider, the gateway calls each MCP server with a credential that server accepts, admins decide who may use which server, and every call is audited. The codebase is a new module: a Python service with its command-line client and SDK, the files that build its Docker image, its documentation, its pages for Gravitino's web UI, and changes to existing Apache Gravitino files that build, package and document it.

    Project info

    • Which PMC will be responsible for the code: Apache Gravitino PMC
    • Into which existing project/module: Apache Gravitino. The gateway goes into a new repository, https://github.com/apache/gravitino-mcp-gateway; its web UI pages and its changes to existing Gravitino files may also go into https://github.com/apache/gravitino.
    • Officer or member managing donation: Jerry Shao (jshao), VP Apache Gravitino
